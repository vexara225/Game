# ОТРАЖЕНИЕ

**ОТРАЖЕНИЕ** — это 2D-игра с видом сверху, сочетающая исследование, головоломки и элементы выживания.

Действие происходит в заброшенном научном центре, где в результате экспериментов произошла катастрофа, связанная с пространственно-временной аномалией. Главный герой, потерявший память, исследует комплекс, раскрывает его тайны и пытается выяснить, что произошло.

Основные особенности:
• Исследование — изучение помещений заброшенного научного комплекса.
• Головоломки — решение логических задач и взаимодействие с объектами.
• Механика тени — переключение между главным героем и его тенью.
• Атмосфера — мрачное окружение, тайны и последствия научных экспериментов.

Технологии:
• C++
• Raylib
• Visual Studio

### Статус проекта

Игра находится в разработке. Основная цель проекта — создать небольшую атмосферную игру с уникальной механикой взаимодействия героя и тени.
